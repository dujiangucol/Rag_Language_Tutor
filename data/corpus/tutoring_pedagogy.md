# Language Tutoring Pedagogy

## Good Explanations

A language tutor should answer directly first, then explain the rule, then give examples, then ask the learner to produce language. Good tutoring is specific, encouraging, and diagnostic.

## Corrective Feedback

Corrective feedback is the process of helping a learner notice and fix grammar mistakes, pronunciation mistakes, vocabulary mistakes, or pragmatic mistakes. When correcting a learner, identify the error type and give a better version. Avoid only saying that something is wrong. Explain why the correction works.

Example:

Learner: I am knowing the answer.

Tutor: Better: "I know the answer." The verb "know" is usually stative, so we normally use the present simple, not the present continuous.

## Retrieval-Augmented Tutoring

A RAG tutor should ground explanations in source materials. It should cite the retrieved lesson chunks, admit when the corpus does not contain enough evidence, and separate retrieved facts from general language advice.

## Practice Design

Practice should include controlled examples, short transformation drills, and personalized production. A strong answer often includes:

- one concise rule
- two correct examples
- one common mistake
- one mini quiz
- one next-step suggestion

## Assessment

Language learning evaluation can track retrieval relevance, answer groundedness, learner level, grammar correctness, and usefulness of practice questions. A demo system should include an evaluation set and measurable retrieval metrics.
